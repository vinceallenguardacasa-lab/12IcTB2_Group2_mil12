💖 About

About This Website

BINI: Media and Information Literacy is an educational platform designed to help students understand Media and Information Literacy (MIL) through interactive lessons, quizzes, and games.

The website uses a BINI-inspired visual theme — pastel colors, flowers, sparkles, hearts, and butterflies — to make learning more enjoyable and engaging. BINI is an eight-member Filipino girl group, and this project is a fan-inspired school work that celebrates their bright and colorful spirit. 🌸
